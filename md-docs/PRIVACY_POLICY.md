# Политика конфиденциальности Torvalds VPN

Редакция от 11 августа 2026 года.

Оператором обработки данных является владелец сервиса Torvalds VPN. Обращения по вопросам конфиденциальности принимаются через канал поддержки, указанный в сервисе.

## Какие данные обрабатываются

Сервис обрабатывает данные, необходимые для создания аккаунта, входа, выдачи подписки и поддержки: адрес электронной почты, имя пользователя, Telegram ID и Telegram username при входе через Telegram, внутренние идентификаторы аккаунта и подписки.

Для управления подпиской обрабатываются её срок, статус, тариф, лимит устройств, технические данные доступа и сведения об оплате. При платеже сервис получает данные об операции, включая сумму, способ и статус платежа, а также идентификатор операции у платёжного провайдера. Реквизиты банковских карт сервис не запрашивает и не хранит.

Для работы и защиты сервиса обрабатываются технические данные: IP-адрес, сведения об устройстве и приложении, данные соединения, журналы обращений, сведения о трафике и события, связанные с ограничением злоупотреблений.

При обращении в поддержку обрабатываются содержание обращения, приложенные файлы и данные, которые пользователь сообщает сам.

## Для чего нужны данные

Данные используются для регистрации и входа, предоставления доступа к VPN, обработки платежей, продления подписки, соблюдения лимитов устройств, защиты от злоупотреблений, ответов на обращения и выполнения обязанностей, установленных применимым правом.

Сервис не продаёт и не передаёт персональные данные рекламным сетям, дата-брокерам или иным лицам для их собственной рекламы. Данные не используются для построения рекламных профилей пользователя.

## Кому могут передаваться данные

Доступ к данным получают только лица и подрядчики, которым он требуется для работы сервиса. К таким получателям могут относиться платёжные провайдеры, почтовые и уведомительные сервисы, поставщики инфраструктуры и технической поддержки.

Передавается только тот объём данных, который нужен для конкретной услуги. Получатели обязаны использовать данные только для согласованной цели и защищать их в пределах применимых к ним обязательств.

Мы собираем только базовый минимум данных для поддержания работы сервиса. Даже если государственные службы запросят какие-либо данные, то никакой чувствительной информации они не получат.

## Хранение и защита

Сервис хранит данные в течение срока, необходимого для работы аккаунта и подписки, расчётов, защиты сервиса, рассмотрения обращений и выполнения обязанностей по закону. Разные категории данных имеют разные сроки хранения. После удаления аккаунта отдельные технические журналы, сведения о платежах и данные внешних сервисов могут сохраняться на период, необходимый для безопасности, урегулирования споров или выполнения требований закона.

Для защиты данных применяются организационные и технические меры, ограничивающие доступ к ним. Доступ предоставляется по служебной необходимости.

## Права пользователя

Пользователь может запросить сведения об обрабатываемых данных, исправление неточных данных или удаление аккаунта, если этому не препятствуют применимое право, незавершённые расчёты или необходимость защиты сервиса. Запрос направляется через поддержку.

Пользователь может удалить профиль подключения со своего устройства в любой момент. Это не удаляет аккаунт и данные, уже переданные сервису.
