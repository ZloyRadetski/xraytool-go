## Requirements

### R1. Исправление SQL Injections и Account Takeover
Функция поиска по Telegram ID (`findUserByTelegramID`) должна использовать точное совпадение (exact match) или безопасный JSON-поиск, чтобы исключить пересечения ID (substring match). 

### R2. Исправление состояний гонки (Race Conditions)
Обновления баланса пользователей и проверка лимитов устройств должны стать атомарными. Использовать `gorm.Expr("balance + ?", amount)` или оборачивать чтение/запись в SQL-транзакции.

### R3. Устранение RCE и несовместимости с ОС
Вызовы системных команд (`exec.Command`, `exec.CommandContext`) должны быть защищены от инъекций аргументов. Использование `/dev/stdin` для стриминга в Xray API должно быть заменено на создание и передачу временных файлов (`os.CreateTemp`), чтобы код работал на Windows.

### R4. Устранение логических багов (Webhook и Рефералы)
Начисление реферальных бонусов должно быть защищено от повторного вызова (проверять `RowsAffected` при изменении статуса платежа). Роут вебхука должен быть вынесен из-под middleware `X-API-Key`.

### R5. Устранение утечек ресурсов и уязвимой криптографии
Утечка файлового дескриптора в `logger.Close()` должна быть закрыта (сброс `out` в `os.Stdout`). Фолбэк генерации в `generate.Secret` должен быть удален (или возвращать ошибку).
